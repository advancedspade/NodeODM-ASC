    Getting started

    What this app does

    This app turns drone photos into maps. You upload a set of overlapping aerial images, the server processes them with OpenDroneMap (ODM), and you get back an orthophoto (a single, flat, measurable map image) plus related outputs such as a point cloud and a PDF report.

    Finished outputs are saved to cloud storage under the project name you choose, so the whole team can find, download, preview, and re-process them later from the Projects page.

    Signing in

    Open the app and click Continue with Google. Only @aspadeco.com Google accounts can sign in; other accounts see “This Google account is not allowed for this site.”

    Your sign-in lasts about 30 days on the same browser. When you are signed in, your email and a Sign out button appear at the top of the Home page.

    Finding your way around

    The sidebar on the left switches between the main pages:

    • Home — upload drone images and start a processing job. Your running and finished jobs are listed on the right.
    • Uploads — send files that are already processed (GeoTIFFs, point clouds, ZIP archives) straight to cloud storage.
    • Projects — every project in cloud storage, with its status, downloads, previews, and re-processing.
    • Feedback — report a bug or suggest an idea (shown when feedback is set up on the server).
    • User guide — opens this page.

    Use the ‹ button at the top of the sidebar to collapse it and give the page more room.

    Processing a drone job

    Adding images and GCP files

    On the Home page, drag your drone photos into the drop zone under Images & GCP (optional), or click the drop zone to pick files. You can add more files in several batches before starting.

    If you have ground control points (GCPs), add the GCP file along with the images. GCPs tie the map to surveyed positions on the ground and improve its accuracy.

    The number of selected files is shown under the drop zone. Use Remove all files to empty the drop zone and start over.

    Using a ZIP URL instead

    If your images are already online in a single ZIP file, click Use ZIP URL instead and paste the link. The server downloads the ZIP itself, so nothing has to pass through your browser. Click Switch to file upload to go back to the drop zone.

    Naming your project

    Every job needs a Project name. It appears in the task list and becomes the folder name in cloud storage, so choose something you will recognise later, such as North field survey.

    Names must be unique. Special characters are removed when comparing names, so North-field survey and North field survey count as the same project. A message under the field warns you if the name is already taken.

    Click ↺ next to the field to clear it.

    Checking image locations on the map

    As soon as you add images, the Image locations map reads the GPS position stored in each photo and shows it as a pin. Use it to confirm that you picked the right flight and that no photos are missing or out of place.

    Click a pin to see the file name and coordinates. Use Hide map to collapse the map if you do not need it.

    If you see pins but no map background, the map imagery service is not set up on this server. The pins and all other features still work.

    Excluding photos from processing

    You can leave out photos you do not want processed, such as takeoff and landing shots or images over the wrong area. Excluded photos are marked as deselected on the map and are not sent to the job.

    • Deselect mode (the circle-with-a-line button on the map): turn it on, then click individual pins to exclude or include them.
    • Draw polygon (the shape button): click the map to place the corners of an area, then click Finish area. Every photo inside the shape is excluded. Click Cancel to stop drawing.

    Checking RTK quality

    When you add photos from a DJI drone with RTK positioning, the RTK Analysis panel checks the positioning quality stored in each image automatically. A badge summarises the result, and a banner warns you if many photos have a weak position fix.

    Open Flagged images & full report to see which photos were flagged and why. This helps you decide whether to exclude them or re-fly the area before spending time on processing.

    Starting the task

    When your images and project name are ready, click Start task. The button changes to Uploading… and progress bars show how many files have reached the server. Keep the tab open until the upload finishes.

    Once the upload is complete, the job appears in the Tasks list on the right and processing begins. You can close the tab after that; the job keeps running on the server.

    Clear files removes the selected images without starting anything.

    Processing options

    Showing hidden options

    The defaults are tuned for our usual orthophoto work, so most jobs need no changes. To adjust settings, click Show hidden options under the Start task button.

    Hover over or focus the i icon next to any option to read what it does. Click ↺ to put a single option back to its default.

    Point cloud tiles

    Generate 2D and Potree point cloud tiles adds an extra step after processing that builds web-friendly versions of the point cloud. It uses more disk space and time, so leave it off if you only need the standard outputs.

    Webhook URL

    A webhook lets another system know when a job finishes. Enter an HTTPS address and the server sends it a message when the job completes, fails, or is cancelled. Leave the field empty if you do not need this.

    Processing speed (max-concurrency)

    max-concurrency controls how many parts of a single job run side by side. More means faster, but each part needs memory.

    If you leave it unchanged, the server picks a value based on how much memory the machine has, which keeps large jobs fast without running out of memory. Only change it if you have a specific reason; if you set a value that is too high for the machine, the server lowers it automatically.

    Tracking your tasks

    Task statuses

    Each job in the Tasks list shows its name and status. The list refreshes every few seconds.

    • ⏳ Queued — waiting for a free processing slot.
    • ⚙ Running — being processed. Expand the task to see a progress bar.
    • ✓ Completed — finished successfully; downloads are available.
    • ! Failed — processing stopped with an error. Check the console output for the reason.
    • ⊘ Canceled — stopped by someone before it finished.

    Task details and console output

    Click a task to expand it. You will see its ID, name, number of images, status, and how long it has been running.

    Next to Console output, click View to watch the processing log live, or Export to save it as a file. The log is the best place to look when a job fails, and it is useful to attach when reporting a problem.

    Downloading results

    When a task is completed, expand it and click All assets (ZIP) to download everything it produced.

    When cloud storage is connected, quick links also appear for the most common files: GeoTIFF Orthophoto, Point Cloud, and Report PDF. If map tiles were generated, Preview orthophoto opens the map in your browser without downloading it.

    Cancelling, restarting, and removing tasks

    • Cancel stops a queued or running job.
    • Restart runs a cancelled job again.
    • Remove takes a finished, failed, or cancelled job off the list and frees space on the processing server. Outputs already saved to cloud storage are kept and remain available from Projects.

    Recovering interrupted uploads

    Retrying files that did not upload

    If some files fail to upload, a message tells you how many and confirms that nothing has been processed yet. Click Retry failed files to send just those files again.

    Resuming a task after a dropped connection

    If all files uploaded but the job did not start (for example, your connection dropped at the last step), click Resume task to start processing with the files already on the server. Click Discard upload to throw them away instead.

    Uploads where processing never started

    If you closed the tab or lost your connection partway through, the app lists the unfinished upload the next time you open it. The file count shows only the files that reached the server, which can be fewer than you selected.

    • Resume starts processing with the files that arrived.
    • Add remaining files lets you add the missing files to the same upload before starting.
    • Discard deletes the partial upload.

    Uploading to cloud storage

    Choosing a project title

    The Uploads page sends files that are already processed straight to a project in cloud storage. Start typing in Project title to search existing projects, then pick one from the list to add files to it. To create a new project, type a new title and press Enter.

    The line under the field shows the exact folder name the files will go into. Spaces become underscores. Click Refresh if a recently created project is missing from the list.

    Adding files or folders

    Drop files, a folder, or a .zip into the drop zone, or click it to browse. Use Choose folder… to pick a whole folder; your browser may ask you to confirm once.

    For very large outputs, or folders with thousands of small files (such as point cloud tile folders), zip the folder first and upload the single .zip. It is much faster, and the server unpacks it into the project for you.

    Click Remove next to a file to drop it from the list, or Clear files to start over.

    Upload progress and the activity log

    Click Upload to start. The progress bar covers two steps: first your files are sent, then the server finishes copying them into the project (and unpacks any .zip). The elapsed time, a live status line, and a log of each step appear under the bar.

    Errors are labelled in red in the log. If an upload stalls or the server restarts, the app tries to pick up where it left off automatically.

    Managing projects

    Searching and filtering projects

    The Projects page lists every project folder in cloud storage. Type in Search by project name… to narrow the list, and use the filter buttons to show only one status: All, Incomplete, Succeeded, Failed, In progress, or Archived.

    Click Refresh to reload the list.

    Project statuses

    • Succeeded — processing finished and an orthophoto was produced.
    • In progress — a job for this project is queued or running.
    • Failed — the last job failed or was cancelled.
    • Incomplete — the folder has no orthophoto yet, for example only raw images were uploaded.
    • Archived — moved out of the main list. Its files are kept.

    Each project shows when it was started, how many images it used, and who started it. Open Activity to see the history of what happened to it and who did it.

    Browsing and downloading files

    Click Download ZIP to download a whole project at once.

    To get individual files, open Browse files. You can open folders, download a single file, or tick several files (or a whole folder) and click Download selected as ZIP.

    Previewing an orthophoto

    If a project has map tiles, a Preview orthophoto button opens the orthophoto on an interactive map in your browser. Zoom and pan to check the result without downloading a large file. Close the preview with Close or the × button.

    Creating a CAD orthophoto

    Full-resolution orthophotos are often too large for CAD software. Under Browse files, the CAD orthophoto section makes a smaller GeoTIFF that CAD tools can open.

    1. Enter the ground resolution you need (for example 5) and choose the unit: cm, m, or ft (US survey). A larger number gives a smaller file.
    2. Choose Keep source CRS to keep the map's current coordinate system, or Reproject and pick a target zone. Use Other EPSG to type a code that is not in the list.
    3. Click Create CAD orthophoto. The job runs in the background; large orthophotos can take a while.
    4. When it is ready, click Download CAD orthophoto.

    Re-processing a project

    If a project still has its raw images in cloud storage, click Re-process to run it again, for example after a failed job or to try different options.

    The app takes you to the Home page and prepares the images directly on the processing server, so nothing large is downloaded to your computer. Review the map, exclude photos or change options if needed, then click Start task.

    If the project already succeeded, you are asked to confirm first. Its existing outputs are replaced when the new job finishes.

    Cancelling, archiving, and restoring projects

    Cancel appears while a project's job is queued or running, and stops it.

    Archive moves a project out of the main list to keep things tidy. Nothing is deleted. Find it again with the Archived filter, and click Restore to bring it back.

    Sending feedback

    Reporting a bug or suggesting an idea

    Click Feedback in the sidebar (or on the Projects page). Choose a Category first; the form then shows the fields that category needs, such as severity or priority for a bug. Fill them in and click Send feedback.

    For problems with a job, include the project name and, if possible, the exported console output. That helps the team find the cause quickly.

    Troubleshooting

    “Cloud storage is not connected”

    The Projects and Uploads pages need cloud storage. If you see this message, the server cannot reach it right now. Processing jobs can still run, but their outputs will not appear in Projects. Let the team know through Feedback.

    The map shows pins but no background

    The map imagery service is not configured on this server. GPS pins, excluding photos, and processing all still work normally.

    “A project named … already exists in cloud storage”

    Project names must be unique, and names that differ only by punctuation or spaces count as the same. Pick a different name, or use Re-process on the Projects page if you meant to run the existing project again.

    My job is taking a long time

    Large flights (hundreds of images) can take hours. Jobs may also wait as Queued while the server finishes other work. Check the task's progress bar and console output; if the log is still moving, the job is working normally.

    My job failed

    Expand the task and open the console output; the last lines usually explain the problem. Common causes are too little overlap between photos, photos without GPS, or very few images. Fix the input and use Re-process, or send the exported log through Feedback.
